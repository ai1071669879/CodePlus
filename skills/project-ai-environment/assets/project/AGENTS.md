# 项目 AI 核心规则

## 开始任务
1. 读 Docs/ai/README.md、Docs/ai/project-adaptation.md，按 rules.json 加载本任务规则。
2. `python tools/ai/check_env.py whoami` 核账号、岗位与路径；记分支/HEAD/已有改动、目标/范围/门禁。

## 修改边界
- 先理解、查找并复用；简单、精准，验收驱动。
- 未授权或缺规则只读；不自授、不覆盖他人改动；当前分支工作，切换/提交/发布按指令。
- 敏感/跨职责变更按授权；生成物用正式工具；保护凭据与隐私，保留已有更严约束。
- 设计与验收由任务负责人承担；接力记 Tasks。

## 交付验收
- 说明改动/影响/风险/未验证项，附命令、退出码和证据；先编译后运行，性能另验，不降低测试标准。
- 环境检查：`python tools/ai/check_env.py check`；工程门禁另验。
